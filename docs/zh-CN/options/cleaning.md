# 清理

默认情况下，`tsdown` 会移除输出目录（`outDir`）中的**过期文件**。本次构建再次生成的文件会被原地覆盖；上次构建留下、而这次没有再生成的文件，只会在新产物写入磁盘之后被删除。

监听模式在每次成功的重新构建后使用同一规则。在 `tsdown --watch` 运行时读取 `outDir` 的工具（Vite、Nest、`tsc --watch`）会一直看到上一份文件，直到该文件被替换。目录不会先被清空。

写入同一输出目录的构建（包括同一个包的 ESM 和 CJS）会一起清理。每个格式保留自己刚写出的文件。只有当它们都不再生成的文件，才会在最后一个构建结束后被删除。

用 `--no-clean` 可以完全关闭清理：

```bash
tsdown --no-clean
```

> [!NOTE]
> `clean: true` 仍会删除清理目标中本次构建没有生成的全部文件。不要把它指向还需要保留其他文件的目录。
